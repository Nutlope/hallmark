Plain-text books that balance themselves.

Ledger is a double-entry bookkeeping CLI for developers who'd rather keep accounts in a file they own than a SaaS dashboard. Every entry is a line of text; every report is one command.

Books as a file, not a service

Append entries

Write transactions in a readable journal format. Comments and tags travel with each line.

ledger add "rent" -120000 assets:checking

Run reports

Balance sheets and income statements are commands, not screens. Pipe the output anywhere.

ledger report balance --period 2026

Diff your money

Because the journal is text, git tracks every change. Review your finances like code.

git diff books.journal
